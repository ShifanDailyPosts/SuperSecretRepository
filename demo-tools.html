1. HTML5 Pondasi & Kerangka

Analogi: Tulang belulang dan struktur dinding pada sebuah bangunan arsitektur.
Buka Modul Belajar & Soal ↗

HTML (HyperText Markup Language) adalah standar bahasa markup universal untuk menyusun kerangka konten di internet. Tanpa HTML, browser tidak tahu mana judul, paragraf, gambar, tombol, atau navigasi.

  • HTML5 Semantik Modern: Tag seperti <header>, <nav>, <main>, <section>, dan <footer> memudahkan mesin pencari (SEO) dan pembaca layar tuna netra (A11y).
  • Struktur Hirarki Rapi: Membagi konten menggunakan heading bertingkat (<h1> sampai <h6>) untuk keterbacaan optimal.
  • Embed Multimedia Canggih: Mendukung pemutaran audio, video native, canvas animasi, dan format SVG tanpa plugin eksternal.
💡 Tips Pro Shifan: Selalu sertakan atribut alt="" pada setiap tag <img> dan pastikan hanya ada satu <h1> utama per halaman agar skor SEO Google tembus 100%!
index.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <title>Portofolio Shifan</title>
</head>
<body>
  <header class="santri-header">
    <h2>Halo Dunia! Saya Shifan</h2>
    <p>Santri & Web Developer masa depan.</p>
  </header>
  <button type="button" class="cta-btn">Hubungi Saya</button>
</body>
</html>

2. CSS3 Gaya, Estetika & Responsif

Analogi: Desain interior, warna cat neon, pencahayaan, dan dekorasi mewah gedung.
Buka Modul Belajar & Soal ↗

CSS3 (Cascading Style Sheets) adalah bahasa seni yang mengubah kerangka HTML hambar menjadi mahakarya visual yang menawan, estetik, dan responsif di layar HP, tablet, maupun monitor desktop.

  • Flexbox & CSS Grid: Tata letak dinamis 1 dimensi dan 2 dimensi yang otomatis menyesuaikan ukuran layar tanpa merusak susunan.
  • Glassmorphism & Backdrop-Filter: Efek kaca transparan buram (frosted glass) yang menjadi tren website kelas dunia.
  • Keyframe Animations & Transitions: Animasi lembut untuk tombol hover, banner melayang, dan efek cahaya neon.
💡 Tips Pro Shifan: Gunakan variabel CSS (:root { --primary: #38bdf8; }) agar jika ingin mengganti tema website dalam sekejap, cukup ubah satu baris saja!
styles.css 
.glass-card {
  background: rgba(15, 23, 42, 0.75);
  backdrop-filter: blur(16px);
  border: 1px solid rgba(56, 189, 248, 0.3);
  border-radius: 16px;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.4);
  transition: transform 0.3s ease;
}
.glass-card:hover {
  transform: translateY(-4px);
}

3. JavaScript (ES6+) Otak, Logika & Interaktivitas

Analogi: Sistem kelistrikan, tombol pintar, elevator otomatis, dan sensor gedung.
Buka Modul Belajar & Soal ↗

JavaScript adalah bahasa pemrograman utama dunia web. JavaScript memberikan jiwa dan reaksi hidup pada website: mendengarkan klik pengguna, kalkulasi angka, animasi real-time, dan komunikasi data API tanpa refresh halaman.

  • DOM Manipulation: Menambah, mengubah, atau menghapus elemen HTML secara live berdasarkan tindakan pengguna.
  • Event Listeners: Memantau aksi pengguna seperti click, keydown, scroll, atau submit.
  • Asynchronous & Fetch API: Mengambil data dari server backend atau AI secara background (async/await).
💡 Tips Pro Shifan: Selalu gunakan const atau let, hindari kata kunci kuno var untuk mencegah bug scope yang membingungkan!
script.js 
let clickCount = 0;
const btn = document.getElementById('clickBtn');
const display = document.getElementById('counter');

btn.addEventListener('click', () => {
  clickCount++;
  display.textContent = clickCount;
  // Reaksi interaktif!
  btn.style.transform = 'scale(0.95)';
  setTimeout(() => btn.style.transform = '', 150);
});

4. Python Otomasi, Backend & Sains Data

Analogi: Mesin super cerdas di ruang kontrol pusat dan asisten peneliti laboratorium.
Buka Modul Belajar & Soal ↗

Python adalah bahasa terpopuler di dunia untuk Artificial Intelligence, Machine Learning, scripting automasi, dan backend development. Sintaksnya bersih, mirip bahasa Inggris, dan sangat mudah dipelajari santri pemula.

  • Syntax Elegan & Bersih: Tidak memerlukan titik koma (;) dan menggunakan indentasi spasi yang rapi secara alami.
  • Raksasa Ekosistem AI & Sains: Pustaka kelas dunia seperti NumPy, Pandas, TensorFlow, PyTorch, dan FastAPI.
  • Otomasi Skrip Cepat: Mengotomasi tugas rutin seperti scraping web, merapikan ribuan file, hingga backup database.
💡 Tips Pro Shifan: Manfaatkan f-string Python (f"Nilai: {nilai}") untuk menyusun teks dinamis secara cepat dan mudah dibaca!
grading.py 
def evaluasi_santri(nama, nilai_hafalan, nilai_koding):
    rata = (nilai_hafalan + nilai_koding) / 2
    if rata >= 90:
        predikat = "Mumtaz (Istimewa) 🏆"
    elif rata >= 80:
        predikat = "Jayyid Jiddan (Sangat Baik) ⭐"
    else:
        predikat = "Jayyid (Baik) 👍"
    return f"{nama}: Rata-rata {rata:.1f} - Predikat: {predikat}"

5. Git & GitHub Version Control & Kolaborasi

Analogi: Mesin waktu penyelamat kode dan jembatan kolaborasi tim internasional.
Buka Modul Belajar & Soal ↗

Git adalah sistem pengontrol versi terdistribusi yang mencatat setiap jengkal perubahan kode. GitHub adalah rumah cloud tempat kamu menyimpan repositori, berkolaborasi dengan developer dunia, dan memamerkan portfolio ke recruiter.

  • Checkpoint Bebas Takut: Jika kodingan rusak karena salah ketik, kamu bisa kembali ke commit sebelumnya dalam 1 detik.
  • Branching & Merging: Buat cabang fitur baru tanpa mengganggu kode utama yang sedang berjalan live.
  • Portofolio Publik Developer: Jejak commit hijau (contribution graph) membuktikan keaktifan belajarmu secara objektif.
💡 Tips Pro Shifan: Tulis pesan commit dengan format imperatif singkat, contoh: feat: tambahkan landingpage tools alih-alih cuma update file!
Git CLI Workflow 
# 1. Cek status berkas
git status
# 2. Rekam perubahan ke staging
git add .
# 3. Kunci perubahan dengan pesan jelas
git commit -m "feat(tools): rilis panduan 7 tools interaktif"
# 4. Kirim ke repositori cloud GitHub
git push origin main

6. Hostinger FTP Web Hosting & Cloud Deployment

Analogi: Kunci emas dan alamat resmi agar karyamu bisa dikunjungi seluruh manusia di muka bumi.
Buka Modul Belajar & Soal ↗

Hostinger FTP (File Transfer Protocol) adalah pintu gerbang komunikasi file antara komputer lokal kamu dengan web server cloud. Melalui FTP, file website dipublikasikan secara instan ke domain internet (seperti shifandailyposts.mediasosial.net) dengan perlindungan SSL HTTPS.

  • Penerbitan Nyata 24/7: Website aktif tanpa henti di server cloud dengan performa kencang LiteSpeed.
  • Automasi Script PowerShell: Deploy otomatis dengan script upload_ftp.ps1 sekali klik tanpa harus login manual berulang-ulang.
  • Keamanan Konfigurasi .htaccess: Mengunci proteksi CSP, cache browser, dan routing aman langsung di server.
💡 Tips Pro Shifan: Selalu tes halaman di server staging/demo terlebih dahulu sebelum menimpa berkas index.html utama agar pengunjung tidak mendapati error!
upload_ftp.ps1 
# Upload via System.Net.WebClient (PowerShell)
$client = New-Object System.Net.WebClient
$client.Credentials = New-Object System.Net.NetworkCredential($username, $password)
$ftpUrl = "ftp://$ftpServer/demo-tools.html"
$client.UploadFile($ftpUrl, "STOR", "d:\Portofolio Shifan\demo-tools.html")
$client.Dispose()
Write-Host "✅ Uploaded to Hostinger Server Successfully!"

7. VS Code Editor Utama & Produktivitas

Analogi: Meja kerja lengkap tukang kayu modern dengan segala perkakas terbaik di dunia.
Buka Modul Belajar & Soal ↗

Visual Studio Code (VS Code) adalah code editor terfavorit di bumi bagi jutaan programmer. Ringan, cepat, memiliki ribuan ekstensi produktivitas, terminal terintegrasi, dan auto-completion cerdas (IntelliSense).

  • Integrated Terminal: Jalankan PowerShell, Git Bash, atau WSL langsung di dalam editor tanpa berpindah jendela.
  • Ekstensi Sakti: Prettier (perapih kode otomatis), Live Server (auto reload di browser), ESLint, dan GitHub Copilot.
  • Keyboard Shortcut Dahsyat: Mengedit puluhan baris sekaligus menggunakan multi-cursor dan pencarian cepat command palette.
💡 Tips Pro Shifan: Tekan Ctrl + P untuk membuka file apa pun secara kilat tanpa harus mengklik folder satu per satu di sidebar!
