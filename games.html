CodeQuest: Petualangan Koding Santri Developer

CodeQuest adalah game interaktif petualangan santri di mana kode pemrograman adalah senjatamu! Hadapi boss monster syntax error dan susun kodingan nyata langsung di browser.

  • Stage 1: HTML Dungeon Pilih dan letakkan tag penutup semantik yang hilang untuk memperbaiki struktur DOM yang hancur.
  • Stage 2: CSS Neon Alchemy Racik kombinasi warna gradien, border-radius neon, dan backdrop-filter blur untuk membuka perisai visual.
  • Stage 3: JS Reactor Explosion Picu event listener klik dan hitung variabel reaktif untuk melipatgandakan serangan kombo kritikal!
