HTML Markup Language

Pondasi Arsitektur Semantik, Aksesibilitas (A11y) & Struktur Web Modern

Tingkat: Komprehensif & Mendalam 5 Soal Latihan (Acak Setiap Sesi)
1. Ringkasan & Fungsi HTML

HTML (HyperText Markup Language) adalah bahasa markup standar yang menjadi pondasi dasar seluruh website di internet. Jika diibaratkan membangun rumah, HTML adalah tiang penyangga, dinding, lantai, dan atapnya sebelum rumah tersebut dicat dan dihias.

Penyusun Struktur

Menyusun hierarki dokumen dari judul (heading), paragraf, gambar, formulir, hingga tata letak navigasi.

Berbasis Tag Semantik

Menggunakan tag semantik seperti <header>, <nav>, <main>, dan <footer> agar ramah mesin pencari (SEO).

Standar Global W3C

Dapat dieksekusi secara universal oleh semua web browser tanpa memerlukan instalasi compiler tambahan.

2. Pelajaran Pembukaan: Anatomi Dokumen HTML Pertama Kamu

Setiap halaman web modern selalu diawali dengan dokumen HTML standar. Mari pelajari kerangka dasar yang wajib kamu ketahui:

index.html (Struktur Dasar) 
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Portofolio Santri Developer</title>
</head>
<body>
    <header>
        <h1>Halo Dunia, Saya Shifan!</h1>
        <p>Santri di Hiraa Center & Pengembang Web</p>
    </header>

    <main>
        <section>
            <h2>Tentang Saya</h2>
            <p>Belajar coding dengan tekun untuk menebar manfaat.</p>
            <a href="https://github.com" target="_blank">Kunjungi GitHub Saya</a>
        </section>
    </main>
</body>
</html>
1
<!DOCTYPE html> & <html lang="id">

Deklarasi awal dokumen: '<!DOCTYPE html>' memberitahu peramban agar merender halaman menggunakan standar HTML5 modern (bukan Quirks Mode lama). Atribut 'lang="id"' (Bahasa Indonesia) sangat penting bagi mesin pencari (SEO) dan memungkinkan software pembaca layar (Screen Reader) melafalkan teks dengan intonasi serta aksen bahasa Indonesia yang tepat.

2
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Kunci wajib website responsif di layar ponsel/tablet. Tag ini memiliki 2 instruksi vital: (1) 'width=device-width' menyelaraskan lebar halaman web dengan lebar fisik layar smartphone dalam satuan CSS pixel (bukan resolusi monitor PC), dan (2) 'initial-scale=1.0' menetapkan tingkat pembesaran (zoom) awal pada rasio 100% (1:1 proporsional). Tanpa tag ini, browser smartphone akan memperlakukan website seolah-olah dibuka di layar desktop lebar (default 980px), mengakibatkan halaman mengecil drastis (zoom-out) dan teks menjadi mikroskopis hingga sulit dibaca tanpa dicubit (pinch-to-zoom).

3
Pemisahan Landmark Semantik: <header>, <nav>, dan <main>

Tiga tag struktural resmi W3C dengan fungsi yang sangat berbeda: (1) '<header>' adalah area kepala/pengantar (berisi logo, judul situs, slogan, atau banner atas); (2) '<nav>' khusus membungkus daftar tautan navigasi penting (menu utama) agar pengguna tuna netra dapat langsung mengenali menu tanpa harus membaca seluruh isi halaman; dan (3) '<main>' adalah wadah tunggal konten pokok yang unik pada halaman tersebut. Aturan mutlak W3C: tag <main> HANYA BOLEH ADA 1 KALI per halaman dan tidak boleh dibungkus di dalam header atau footer.

4
Aksesibilitas Formulir: Relasi <label for="id"> dan <input id="...">

Standar aksesibilitas WCAG: nilai atribut 'for' pada tag <label> harus persis sama dengan atribut 'id' pada kotak <input>. Keuntungannya: saat pengguna mengklik atau menyentuh teks label, kursor seketika aktif di dalam kotak input terkait. Ini memperbesar target sentuh di layar ponsel dan mempermudah pengguna disabilitas motorik.

5
Sistem Validasi Input Bawaan HTML5

Atribut 'required' mencegah form dikirim jika belum diisi, atribut 'type="email"' otomatis mengecek keberadaan tanda '@' dan domain surat elektronik, serta 'minlength="3"' membatasi jumlah karakter minimal. Semua pengecekan ini dijalankan otomatis oleh browser secara instan tanpa membutuhkan sebaris pun kode JavaScript.

6
Tautan Aksesibilitas 'Skip-Link' (<a href="#main-content">)

Teknik aksesibilitas profesional: tautan navigasi tersembunyi di posisi paling atas halaman yang baru muncul saat pengguna menekan tombol Tab keyboard. Tautan ini memungkinkan pengguna tunanetra melompati daftar panjang menu navigasi di header dan langsung mendarat pada konten inti halaman (<main id="main-content">).

Tips Santri Developer:

Gunakan tag semantik (seperti <main>, <article>, <section>) daripada hanya menggunakan <div>, agar struktur halamanmu rapi, bersih, dan mudah dibaca oleh Googlebot maupun pembaca layar tunanetra.
